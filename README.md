# aiida-eonclient

This repository is a 2021 AiiDA plugin-cutter stub (`DiffCalculation`
wrapping `diff`). The working plugin is
[`aiida-eon`](https://github.com/HaoZeke/aiida-eon): one `CalcJob` for
`eonclient` (`config.ini`, `pos.con`, `results.dat`).

Do not install this package.
